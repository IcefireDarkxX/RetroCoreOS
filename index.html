Un sistema operativo moderno per computer che molti hanno già buttato.

Che cos'è

RetroCore è una distribuzione Linux minimal per PC del 2009 circa (Pentium 4, Core 2 Duo, 512 MB–2 GB di RAM). È costruita su CorePlus / Tiny Core Linux: il sistema viene caricato interamente in RAM, ed è per questo che un computer che faticava con Windows XP sembra nuovo.

Solo ~250 MB di immagine, avvio in pochi secondi, nessuna telemetria, nessun account.

Menu di avvio pensato per hardware vecchio

  • Predeterminato — avvio normale (sistema in RAM)
  • 512 MB di RAM — senza copia in RAM, resta fluido anche su macchine molto lente
  • Video sicuro — nomodeset: la risoluzione per quando lo schermo resta nero all'avvio (GPU Intel/nVidia 2009)
  • Solo console — senza ambiente grafico, per recupero dati o diagnostica
  • CorePlus originale — avvio non modificato, come piano di riserva

Requisiti

  • CPU i686 (32 bit) o superiore — qualsiasi processore 2009 va bene
  • 512 MB di RAM (consigliati 1 GB per Firefox)
  • Chiavetta USB (per l'uso o l'installazione) oppure CD-R
  • Nessun disco necessario: può girare interamente da USB/CD

Come provarla

  1. Scarica o costruisci la ISO (vedi sotto)
  2. Scrivila su una chiavetta USB con Rufus (modalità DD) o balenaEtcher
  3. Avvia il PC vecchio dalla chiavetta (Nota: se il BIOS non parte da USB, attiva "USB-HDD" o usa un CD-R)
  4. Se ti piace: avvia tc-install dentro RetroCore per installarla sul disco fisso

Ottenere la ISO

Build locale (Linux/WSL2/macOS con Homebrew):

sudo apt install -y wget squashfs-tools xorriso   # Debian/Ubuntu
./build.sh

→ dist/RetroCoreOS-15.x-x86.iso + MD5, pronta per la scrittura su USB.

Oppure senza installare nulla: build automatica nel cloud con GitHub Actions (scheda Actions → build-iso → Run workflow) e scarichi l'artifact che contiene la ISO.

Installare programmi

Dal repository .tcz di Tiny Core (tce-load -wi nome.tcz o app Apps) oppure con file singoli AppImage: scarichi, retrocore-appimage file.AppImage, funziona — senza daemon e senza runtime da gigabyte.

Nota tecnica: Flatpak/Flathub e Snap richiedono systemd e runtime da 1–2 GB: non compatibili con l'architettura di Tiny Core né con 512 MB di RAM.

Persistenza dei dati

La particolarità di Tiny Core: niente viene salvato "in automatico" sulla RAM dove gira il sistema. I tuoi file e le impostazioni si conservano con filetool.sh -b (home e configurazioni in un archivio) e le app aggiuntive con tce-load -wi <nome>.tcz in un percorso su disco/USB scelto al primo avvio.

Perché un'altra distro leggera?

  • Pochi mega, tutto esplicito: sai esattamente cosa è dentro, perché lo scegli tu con una lista di estensioni
  • Menu di avvio già pronta per i guai tipici del 2009 (schermi neri, poca RAM, WiFi mancante)
  • Repository ufficiali di Tiny Core: migliaia di pacchetti, gli stessi tre mirror ufficiali con fallback
  • Kit di build riproducibile: la ISO si rigenera da zero con un solo comando, ogni personalizzazione è un file di testo
