RetroCore Linux
===============
Distribuzione leggera per PC ~2009, costruita su CorePlus (Tiny Core Linux).

Utente:  tc   (nessuna password)
Root:    password "tc" al primo sudo

Salvataggio impostazioni permanenti:   filetool.sh -b
Installazione estensioni aggiuntive:    tce-load -wi <nome>.tcz
Info di sistema:                        retrocore-info
WiFi:                                   retrocore-wifi
